# Theodora Ionescu — Portfolio

A static portfolio website for Theodora Ionescu, showcasing selected creative, marketing, and production projects.

Published at [theodoraionescu.github.io/portfolio](https://theodoraionescu.github.io/portfolio).

## Run locally

No build step or package installation is required. From the project root, start any local HTTP server:

```bash
python3 -m http.server
```

Then open [http://localhost:8000](http://localhost:8000).

## Project structure

- `index.html` and `project.html` — portfolio pages
- `content/` — Markdown text for the home page and projects
- `css/` and `js/` — site styles and interactions
- `images/` and `documents/` — portfolio media and supporting files

To update the website copy, edit the files in [`content/`](content/README.md). Keep the front matter and section headings unchanged.
